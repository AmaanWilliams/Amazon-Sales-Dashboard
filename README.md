# **Amazon Sales Performance Analysis**

## Project overview
This project analyzes Amazon sales data to identify key sales trends, revenue performance, customer behavior, and product category performance. The data was cleaned and analyzed using Microsoft Excel before creating an interactive dashboard in Power BI.

## Data Source
Kaggle link:
https://www.kaggle.com/datasets/aliiihussain/amazon-sales-dataset

## Data Analysis

The analysis focuses on:

- Total revenue and quantity sold
- Sales performance by product category
- Revenue by customer region
- Payment method usage
- Customer ratings
- Discounts and their relationship with revenue
- Sales trends over time
  
## Features
- KPI cards for key sales metrics
- Interactive slicers for filtering the data
- Revenue and sales visualizations
- Product category analysis
- Regional sales analysis
- Interactive Power BI dashboard

## Tools Used
- Microsoft Excel
- Microsoft Power BI

## Project Process
1. Imported the raw Amazon sales dataset
2. Cleaned and prepared the data in Microsoft Excel
3. Created pivot tables to explore the dataset
4. Analyzed key sales metrics and trends
5. Built an interactive dashboard in Power BI
6. Presented the findings using visualizations and KPI cards
